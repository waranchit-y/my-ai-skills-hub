🎯 คำสั่งเริ่มต้นภารกิจ (Onboarding Activation Protocol):
1. คลังสกิลกลางของเราอยู่ที่โฟลเดอร์นี้: ให้คุณสำรวจโครงสร้างไฟล์ทันที โดยเฉพาะ:
   - 'GEMINI.md' (กฎเหล็กวงจร 4 ขั้นตอน: Pre-Check & Route ➔ Disciplined Execution ➔ Evidence Gate ➔ Continuous Learning)
   - '00_ดัชนีรวมสกิลทั้งหมด_CATALOG.md' (สารบัญสกิลทั้งหมด)
   - '00_คู่มือการใช้งานคลังกลาง_START_HERE.md'

2. กฎการทำงานที่คุณต้องปฏิบัติตามทุกครั้งที่ฉันสั่งงาน:
   - [Phase 1: ป้องกันข้อผิดพลาดล่วงหน้า]: ตรวจสอบ Catalog เสมอ และแจ้งแผนงานสั้นๆ (เป้าหมาย / สกิลที่เลือกใช้ / จุดเสี่ยง) ก่อนเริ่มลงมือ
   - [Phase 2: วินัยการทำงาน]: ห้ามลัดขั้นตอน หากเป็นงานใหญ่ให้วางแผนหรือแบ่งงานอย่างมีระบบ
   - [Phase 3: ตรวจสอบจริงก่อนส่งงาน]: ห้ามบอกว่าเสร็จถ้ายังไม่ได้รันเทสต์หรือตรวจผลลัพธ์จริงบนเครื่อง ต้องแสดง Output Log ยืนยัน 0 errors
   - [Phase 4: เรียนรู้และอัปเกรด]: หากฉันติชม หรือมีบทเรียนสำคัญ ให้ทำ Mini-Retro และบันทึกลงในไฟล์ SOP หรือกฎทันที

3. โปรดตอบกลับสั้นๆ เพื่อยืนยันว่าคุณ:

   - พร้อมรับคำสั่งภารกิจแรกทันที!

พร็อมต์ที่ 2: รวบรวมสกิลใหม่ & บทเรียน Mini-Retro ก่อนเลิกงาน (เย็น / เลิกงาน)

ใช้สั่ง AI ที่ทำงานก่อนปิดเครื่อง เพื่อรวบรวมไฟล์ที่สร้างใหม่/แก้ไขลงแฟลชไดรฟ์กลับบ้าน

วันนี้หมดเวลาทำงานแล้ว ก่อนฉันจะปิดเครื่องและกลับบ้าน ให้คุณทำหน้าที่ปิดกะและเตรียมไฟล์อัปเดตกลับบ้าน (Daily Offboarding & Delta Sync Protocol) ดังนี้:

1. [Mini-Retro สรุปงานประจำวัน]:
   - วิเคราะห์ว่าในวันนี้ เราได้สร้างสกิลใหม่, เขียนโค้ดส่วนไหน, มีข้อผิดพลาดอะไรที่พบและแก้ไขได้, หรือมีขั้นตอน SOP / Preset แบบไหนที่พัฒนาขึ้นมาบ้าง
   - เขียนสรุปเป็นไฟล์ 'DAILY_RETRO_LOG.md'

2. [ตรวจจับและรวบรวมไฟล์ที่มีการเปลี่ยนแปลง (Delta Export)]:
   - ค้นหาไฟล์ทั้งหมดที่มีการสร้างใหม่หรือแก้ไขในวันนี้ (ใน '01_SKILLS_LIBRARY', '02_WORKFLOWS_SOP', '03_PRESETS_TEMPLATES', '04_PROJECTS', หรือ 'GEMINI.md')
   - คัดลอกเฉพาะไฟล์ที่มีการเปลี่ยนแปลงเหล่านี้ ไปรวบรวมไว้ในโฟลเดอร์ชื่อ 'USB_SYNC_DELTA' โดยรักษาโครงสร้างโฟลเดอร์ย่อยเดิมไว้ทุกประการ

3. [อัปเดตสารบัญ]:
   - หากมีการเพิ่มสกิลใหม่ ให้เขียนอัปเดตลงใน '00_ดัชนีรวมสกิลทั้งหมด_CATALOG.md' ในโฟลเดอร์ 'USB_SYNC_DELTA' ด้วย

4. [สรุปรายงานการนำกลับ]:
   - แสดงตารางรายการไฟล์ทั้งหมดที่พร้อมให้ฉัน Copy ใส่ Flash Drive กลับบ้าน เพื่อเอาไป Merge รวมกับคลังกลางที่บ้าน

พร็อมต์ที่ 3: ผสานไฟล์จากแฟลชไดรฟ์เข้าคลังกลางที่บ้าน (เมื่อถึงบ้าน)

ใช้สั่ง AI ที่บ้าน (หรือดับเบิ้ลคลิก merge_from_usb.bat) เพื่อดึงของใหม่เข้าคลังกลางและอัปเดตเว็บทันที

ฉันนำไฟล์ที่พัฒนาเพิ่มเติมจากคอมที่ทำงานกลับมาในโฟลเดอร์ USB แล้ว (อยู่ในโฟลเดอร์ 'USB_SYNC_DELTA')

โปรดดำเนินการดังนี้:
1. ทำการผสาน (Merge) ไฟล์ทั้งหมดจาก 'USB_SYNC_DELTA' เข้าสู่คลังกลาง 'C:UsersASUSDesktopAgent Folder' โดยรักษาโครงสร้างโฟลเดอร์ให้ถูกต้อง
2. ตรวจสอบความถูกต้องและรายงานว่ามีสกิล, SOP หรือพรีเซ็ตใดบ้างที่ได้รับการอัปเดตหรือเพิ่มเข้ามาใหม่
3. รันสคริปต์อัปเดตเว็บพอร์ทัล ('node 05_WEB_PORTAL/build_portal.js') เพื่อให้อัปเดตหน้าเว็บและสร้างไฟล์ 'agent_skills_bundle.zip' ใหม่ล่าสุดอัตโนมัติ!

🔄 วงจรการทำงานและซิงค์ข้อมูล (Closed-Loop Synchronization Lifecycle)

A

ก่อนออกจากบ้าน หรือเปิดเว็บที่ทำงาน

เว็บนี้จะคอยอัปเดตและสร้างไฟล์ agent_skills_bundle.zip ให้อัตโนมัติทุกครั้งที่คุณทำงานที่บ้าน คุณสามารถกดปุ่ม "โหลดคลังสกิล (.ZIP)" จากเว็บ หรือก๊อปปี้ใส่ USB Flash Drive ติดตัวไปได้เลย

B

เมื่อถึงคอมที่ทำงาน (เช้า)

แตกไฟล์ zip ไว้ที่คอมที่ทำงาน เช่น C:Users...DesktopAgent Folder แล้วเปิด Cursor, Antigravity หรือ Claude จากนั้นเปิดแท็บ "ชุดคำสั่งคอมที่ทำงาน" แล้วกดคัดลอก "พร็อมต์ที่ 1 (Onboarding)" วางลงใน AI เพื่อปลุกระบบทันที!

C

ก่อนเลิกงานที่ทำงาน (เย็น)

ก่อนปิดเครื่องคอมที่ทำงาน ให้เปิดแท็บ "ชุดคำสั่งคอมที่ทำงาน" แล้วกดคัดลอก "พร็อมต์ที่ 2 (Offboarding)" แปะให้ AI รัน AI จะตรวจหาสกิลใหม่ สรุป Mini-Retro และรวมไฟล์ที่อัปเดตลงโฟลเดอร์ USB_SYNC_DELTA เซฟลงแฟลชไดรฟ์กลับบ้าน

D

เมื่อกลับมาถึงบ้าน

เสียบ Flash Drive เข้าคอมที่บ้าน แล้วกดดับเบิ้ลคลิกไฟล์ merge_from_usb.bat ใน Agent Folder หรือสั่ง AI ด้วย "พร็อมต์ที่ 3" ระบบจะดึงของใหม่เข้าคลังกลาง และอัปเดตหน้าเว็บนี้ใหม่อัตโนมัติทันที 100%!

  1. สร้าง Repository ใหม่บน GitHub เช่น ชื่อ my-ai-skills
